# Rust and TypeScript conventions

Use Rust formatting and Clippy and TypeScript strict mode. Keep domain operations in focused Rust modules and presentation in React components. Model failures and job states explicitly; avoid panics for recoverable I/O or service failures. Keep credentials inside the backend and redact diagnostic output. Use structured Tauri commands and events, scoped permissions, atomic persistence, and verified downloads. Test state transitions and failure recovery with isolated filesystem and HTTP fixtures. Run `pnpm check`, `pnpm test`, and `cargo test --manifest-path src-tauri/Cargo.toml` for relevant changes. Do not add speculative preflight gates that prevent actual operations from running.
